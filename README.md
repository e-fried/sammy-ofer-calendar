# Sammy Offer Calendar

Games and traffic reminders for **Sammy Ofer Stadium in Haifa**, automatically updated from the [official stadium schedule](https://www.haifa-stadium.co.il/לוח_המשחקים_באצטדיון/).

**[Open the calendar](https://e-fried.github.io/sammy-ofer-calendar/)**

## What you get

Two events for every published match:

- **The match**, named with the teams, at the published kickoff time. Its two-hour duration is an estimate.
- **Game traffic**, a block covering the three hours before kickoff. The match details are included in its description.

For a **20:00** kickoff, traffic is **17:00–20:00** and the match is **20:00–22:00**. Times follow Israel’s time zone and display in your calendar’s chosen time zone.

No signup or email access is needed.

## Add to your calendar

Copy this subscription URL:

```text
https://e-fried.github.io/sammy-ofer-calendar/calendar.ics
```

### Google Calendar

1. Open [Google Calendar](https://calendar.google.com/) in a desktop browser.
2. Beside **Other calendars**, choose **+ → From URL**.
3. Paste the URL and click **Add calendar**.
4. If the name appears as a URL, rename it **Sammy Offer Calendar** in that calendar’s settings.

Enable the calendar in your mobile app if it is not already visible.

### Outlook

Open **Calendar → Add calendar → Subscribe from web**, paste the URL, name it **Sammy Offer Calendar**, and save/import. Some company accounts block external subscriptions.

### Apple Calendar

Choose **File → New Calendar Subscription** and paste the URL.

## Does it update automatically?

**Yes.** The service checks the stadium website every six hours. Newly published games and kickoff changes appear in the same subscription after the next successful refresh. Your computer can be off, and you do not need to subscribe again.

Google, Outlook, and Apple Calendar control their own refresh timing, so changes may take longer to appear. [Check the latest source refresh](https://e-fried.github.io/sammy-ofer-calendar/status.json).

**Subscribe by URL for updates.** Downloading and importing the `.ics` file gives you a one-time copy.

The calendar only includes fixtures published by the stadium. If the source cannot be read, the last successful calendar is kept. Games removed from the website are not automatically cancelled—check the official schedule for cancellations. Traffic blocks are planning reminders, not live congestion forecasts.
